# Specification

Normative and draft definitions for TEO decision, capability, routing, execution, and verification behavior.

## Stable terminology

- [`lexicon.md`](lexicon.md) defines the stable TEO terms used across policy, reference behavior, research, and stewardship.

## Cross-boundary evidence

- [`final-execution-provenance.md`](final-execution-provenance.md) defines the optional read-only projection from validated Route-Outcome Evidence into a host-consumable `FinalOutcome` without creating routing or execution authority.

## Specification documents

The remaining files in this directory define bounded runtime, provider, verification, telemetry, calibration, and reference-scope behavior. Where a human-readable document and active machine-readable policy overlap, the active policy remains authoritative unless the document explicitly defines the normative contract.
