# Validation History

Completed validation, evidence-result, and conformance records belong here when they are historical observations rather than reusable methodology or active policy.

A validation-history record preserves what was tested and observed at a particular point in time. It does not become current authority merely because the result once passed. Current authority remains in machine-readable policy, executable configuration, schemas, and the canonical Progress Tracker.
