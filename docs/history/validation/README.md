# Validation History

Completed validation, evidence-result, and conformance records belong here when they are historical observations rather than reusable methodology or active policy.

A validation-history record preserves what was tested and observed at a particular point in time. It does not become current authority merely because the result once passed.

No validation records are migrated into this area in R3. The namespace is established so future completed validation records have a canonical lifecycle location instead of accumulating in methodology or at the `docs/history/` root.
