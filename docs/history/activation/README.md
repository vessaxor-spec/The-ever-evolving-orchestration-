# Activation History

Historical records of staged and activated TEO organizational, team, worker, and specialist topology changes.

These documents preserve the state and decision context that existed when the change was prepared or activated. A historical record may therefore contain statuses such as `staged`, `not active`, or an earlier topology that no longer represents current policy.

Current authority remains in active `policy/`, `community/`, registry, and reference surfaces. Do not use an activation-history record as current routing authority.
