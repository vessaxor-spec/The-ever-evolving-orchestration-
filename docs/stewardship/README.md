## Current reconciliation boundary

Current-state documentation is reconciled from repository truth on `main`; historical release records, dated audits, validation reports, and accepted capsules are not rewritten merely to mirror current implementation state. The current Python clean-architecture migration is compatible post-v1 maintenance and does not displace the evidence-governed live-execution expansion workstream or widen live authority.

## Authority boundary

Stewardship documentation records project state and direction. It does not override machine-readable policy, active routing configuration, schemas, release contracts, or executable reference behavior. Historical release records, dated audits, validation reports, and accepted capsules remain historical evidence and should not be rewritten merely to mirror current `main`.
