# The TEO Manifesto

Models are temporary.

Decisions endure.

Intelligence is no longer scarce.

Choosing it wisely is.

Every routing decision should be explainable.

Every default should be challengeable.

Every evaluation should be reproducible.

No provider deserves permanent preference.

Capabilities matter more than branding.

Evidence outranks opinion.

Architecture should outlive model cycles.

Verification matters when consequences matter.

History should preserve why important decisions were made.

Build systems that evolve without forgetting why they were built.

**Navigate by principles. Adapt by evidence.**
