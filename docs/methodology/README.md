# Methodology

Methods for evaluating routing quality, cost, latency, reliability, reproducibility, and evidence strength.

## Available methods

- [`routing-validation.md`](routing-validation.md) defines how representative task classes are checked for route coverage, ownership, worker selection, risk controls, verification, independence, and dispatch trace completeness.
- [`specialist-allocation.md`](specialist-allocation.md) defines how TEO selects a core team, worker binding, optional domain specialist, supporting teams, risk controls, and verification path.
