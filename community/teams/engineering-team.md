# Engineering Team

## Mission

Implement, debug, refactor, test, and verify software changes.

## Responsibilities

- Repository inspection
- Feature implementation
- Bug fixing
- Refactoring
- Test creation and execution
- Dependency changes
- Build and runtime validation
- Technical documentation handoff

## Preferred implementations

1. Codex Terra for execution, debugging, testing, and repository edits
2. Codex Sol for complex engineering reasoning and cross-component planning
3. Gemini Pro when Codex is unavailable or external technical research is required
4. Local coding models for private, offline, or economical fallback

## Required outputs

- Changed files
- Test results
- Assumptions
- Known limitations
- Rollback notes when applicable

## Verification

Consequential changes must be reviewed by the Review Team and independently checked by the Verification Team.
