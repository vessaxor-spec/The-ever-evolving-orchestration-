# Review Team

## Mission

Challenge plans and outputs before they are accepted.

## Responsibilities

- Architecture review
- Semantic and requirements review
- Code and diff review
- Maintainability review
- Security and risk review
- Assumption challenge
- Scope-change detection

## Preferred implementations

1. Claude Sonnet for semantic, architectural, and adversarial review
2. Codex Sol for engineering reasoning and cross-component effects
3. Codex Terra for executable code review and targeted tests
4. Claude Opus for high-consequence escalation

## Required outputs

- Findings by severity
- Unresolved assumptions
- Required changes
- Accepted risks
- Verification requests

## Independence

The Review Team should not rely solely on the implementation that produced the work being reviewed.
