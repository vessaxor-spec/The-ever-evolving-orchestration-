# TEO Team Architecture

TEO routes work to responsibilities before selecting implementations.

```text
Task
  |
  v
Mission Control
  |
  v
Team
  |
  v
Worker
  |
  v
Capability
  |
  v
Implementation
```

## Core teams

- Mission Control
- Planning Team
- Engineering Team
- Research Team
- Review Team
- Verification Team

## Specialist teams

- Architecture
- Backend
- Frontend
- Mobile
- DevOps
- Infrastructure
- Performance
- Security
- Database
- Data Engineering
- AI Engineering
- Documentation
- QA
- Accessibility
- Release

Models are replaceable implementations. Teams and workers define stable responsibilities.
