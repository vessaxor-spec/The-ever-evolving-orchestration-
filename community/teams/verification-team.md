# Verification Team

## Mission

Determine whether the selected plan and execution satisfy the original requirements.

## Responsibilities

- Reproduce reported failures
- Validate fixes and outputs
- Run targeted and regression tests
- Check evidence against claims
- Confirm acceptance criteria
- Confirm rollback or recovery readiness
- Record verification failures

## Preferred implementations

1. Codex Terra for executable verification and test execution
2. Claude Sonnet for requirements and evidence verification
3. Gemini Pro for source-grounded verification
4. Independent human review for critical decisions

## Required outputs

- Verification status
- Evidence
- Failed checks
- Residual risk
- Recommendation to accept, revise, or reject

## Independence

Consequential work should not be verified only by the same worker and implementation that executed it.
