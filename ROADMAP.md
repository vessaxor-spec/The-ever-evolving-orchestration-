# Roadmap

## Foundation

- Establish project identity and public scope
- Publish the manifesto, constitution, lexicon, and stewardship rules
- Define the initial repository structure

## Routing baseline

- Publish the first routing policy
- Build provider, model, capability, and benchmark registries
- Define escalation and verification policies
- Add practical orchestration examples

## Reference framework

- Add machine-readable configuration examples
- Add a minimal reference implementation
- Add tests against documented routing scenarios

## Community evolution

- Accept evidence-backed updates for new models and providers
- Preserve major historical changes through public capsules
- Introduce proposals only when normal pull requests are insufficient

The roadmap is directional. Routing quality remains the priority.
